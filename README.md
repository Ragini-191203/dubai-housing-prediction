# 🏠 Dubai Housing Price Analysis & Dashboard

An interactive Power BI dashboard analyzing Dubai real estate pricing patterns across neighborhoods, property sizes, and configurations.

## 📊 Dashboard Features
- KPI cards: Average price, highest price, avg price per sqft
- Bar, line, and column charts for price trends
- 5 dynamic slicers for real-time filtering
- Location-wise average price breakdown
- Listing category distribution analysis

## 🔍 Key Insights
- Engineered a derived `price_per_sqft` metric to compare properties fairly
- Identified pricing patterns across neighborhoods and bedroom/bathroom configurations
- Visualised price vs. size trends to deliver actionable real estate insights

Power BI | DAX | Data Cleaning | Dashboard Design
